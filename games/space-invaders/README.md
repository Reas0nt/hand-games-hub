# 🚀 Space Invaders: Hand Control Edition
### *La evolución del arcade clásico mediante Visión Artificial*

## 📝 Descripción General
**Space Invaders: Hand Control Edition** es una reinterpretación del legendario videojuego de arcade, diseñada para demostrar el potencial de la interacción humano-computadora (HCI) sin dispositivos físicos. 

El proyecto sustituye el teclado tradicional por un sistema de **Visión Artificial** que procesa en tiempo real los movimientos del usuario a través de una cámara web. Mediante el uso de redes neuronales para la detección de puntos de referencia (landmarks) en la mano, el jugador se convierte en el controlador, permitiendo una experiencia de juego inmersiva y futurista.

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** Python 3.12 (Optimizado mediante entorno Miniconda).
*   **Motor Gráfico:** Pygame-CE (Community Edition).
*   **Visión Artificial:** OpenCV y Mediapipe (Google).
*   **Algoritmos:** Lógica de colisiones, sistemas de niveles, ráfagas de disparo de IA y patrones de ataque de jefes finales.

## 🎮 Características del Juego
*   **Control Gestual:** Movimiento basado en la base del dedo medio y disparo mediante gesto de pinza.
*   **Progreso por Niveles:** Incluye enemigos blindados, ataques Kamikaze y enemigos de élite con rayos láser.
*   **Final Boss:** Enfrentamiento épico contra un Jefe Gigante con ráfagas de fuego en espiral.
*   **Experiencia de Feria:** Modo pantalla completa y sistema de Hall of Fame (Récords).
